# 2026-11-05：Plutonium CN 身份与规则内容对照

## 范围与方法

本次验证 Truesight 0.1.11 的可选 CN 身份适配，以及同名条目的按需规则正文对照。未修改 Plutonium CN、Quick Insert、其他第三方模块或世界数据；manifest 依赖仍只有 Quick Insert。

自动化使用协议夹具与本机安装数据。安装数据测试在独立 VM 中执行 CN 的 `parser.js`、`utils.js`，使用其实际 UID／哈希函数；DataLoader 返回值由本机 CN JSON 提供。原生合集先复制到临时目录，再用只读 LevelDB 读取副本。此结果证明协议映射和本机数据归组，不等同于运行中 Foundry 的 DataLoader、网络或客户端实机验收。

界面通过独立 Playwright 浏览器加载本机 Foundry V13 样式和 CN 数据夹具。当前工具没有 Foundry MCP 入口；未使用 Computer Use，也未操作真实世界。
